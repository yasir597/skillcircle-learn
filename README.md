# SkillCircle Learn — Homepage

A responsive, static homepage concept for SkillCircle Learn.

## Open locally
1. Extract the project folder.
2. Open `index.html` in a modern browser.
3. Keep `styles.css`, `app.js`, and the `assets` folder beside `index.html`.

## Homepage features
- Responsive layout and mobile navigation
- Dark-first visual palette with a dark/light theme toggle
- Scroll progress indicator and subtle reveal motion
- Reduced-motion support and keyboard-accessible navigation
- Founder section with an optional portrait placeholder

## Add your portrait
Place your image at `assets/founder-photo.jpg`. The page includes a fallback placeholder if the image is missing.

## Scope note
This package is a frontend homepage only. It does not include authentication, a database, user profiles, messaging, AI services, or a deployed website.
